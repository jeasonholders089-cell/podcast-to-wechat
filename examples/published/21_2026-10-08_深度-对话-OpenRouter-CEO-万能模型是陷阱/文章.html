2026 年 7 月，Stripe 的人给 OpenRouter 创始人 Alex Atallah 发了条消息，约见面。几个月后，这笔收购落地。a16z 播客把两个人请到了同一张桌子上：Alex 第一次完整复盘这段交易，Replit 创始人 Amjad Masad 坐在对面，他既是 OpenRouter 的投资人，也是过去一年把 AI 塞进企业机房里最狠的人之一。

整场对话里，他们反复回到一个反直觉的判断：模型越强，越不该让它什么事都做。企业真正花钱买的，不是最聪明的那个模型，而是对自己数据、成本和判断力的控制权。

下面按原话顺序编译，删掉寒暄，数字和判断保留原样。他们聊到了 Stripe 为什么买路由层、企业为什么突然开始算每个任务的成本，以及为什么我们可能要重新发明分工。

「做通用 agent 最糟的地方是，你交给它的活越多，你牺牲的理解就越多。可 agent 不承担任何责任。」

Stripe 为什么买一个「模型路由器」

主播： Alex，这笔收购是怎么发生的？是收到 Patrick 的一条私信吗？

Alex： 没有那么戏剧。我在 A 轮的时候认识了 Stripe 的总裁 Will Gaybrick，后来一直保持联系，我们和 Stripe 各个团队一直有工作流在跑，我也去 Stripe Sessions 讲过东西。今年 7 月，他们主动约我聊，见了真人，然后就推进得很快。整个过程挺高效，对创始人也友好。

主播： 在此之前你想过卖公司吗？

Alex： 没有。但 Stripe 是我心里的第一选择。谈下去之后越来越清楚的是，他们愿意让我们保留品牌、路线图和产品的自主权，OpenRouter 继续做现在的事，只是更快，配一套更认真的 go to market。两家公司在更底层是同一个想法：世界上应该出现更多新公司，而不是所有人都变成一家巨无霸公司的一部分。

Alex： 往后看，支付和推理会融在一起。

路由这门生意，到底在解决什么

Alex： OpenRouter 解决的第一件事是不被模型绑住。你能一直站在性价比前沿，跟着整个生态往上走。这件事比听上去难，因为锁定藏在各种细节里。

Alex： 第二件事是多模型协作。你想要的是「神经多样性」：不同数据、不同方式训出来的模型，包括你自己训的那一个，合起来的效果超过单独用 ChatGPT 或者 Claude。企业买你，是因为如果你只是套在某个模型外面的一层壳，客户迟早会问：我为什么不直接用那个模型？

Alex： 第三件事是成本。有一类生意在成本降下来之前根本不会出现，而要让成本降下来，需要一个真正有效率的公开市场。没有市场，供应商为什么要给你降价？在 OpenRouter 出现之前，这个位置上只有一个玩家：OpenAI。

主播： 公司做了三年，最让你意外的是什么？

Alex： 企业接受开源权重模型的速度，比我预期快。企业通常有很强的品牌依赖，判断不了差别就跟着大公司买。这次没那么明显。很多企业主动想试新模型，一是省钱，二是想做出区分度，想「拥有自己的智能」。这种心态带来一个副产品：很多公司第一次开始做自己的评测和 benchmark，第一次开始算每个任务的成本。

企业要的不是最强模型，是自己的智能

Amjad： 纳德拉在这件事上说得最清楚：每家公司最后都要有自己的 AI 能力，就像每家公司后来都招了软件工程师。这个能力会复利，最后沉淀成公司内部的知识、模型选择和成本结构。

Amjad： Palantir 的 Alex Karp 讲的是另一面：基础模型公司会慢慢走进你的业务里。Harvey 和 OpenAI 之间的关系，已经能看出这种张力。这些公司的雄心是去接管经济里很大一块，你跟它们合作，天然是难的。你去看 SpaceX 的 S-1，标题数字是三万亿美元，而全球 GDP 才一百万亿。

Amjad： 所以 Replit 在往「企业内部的独立层」走：在你和模型之间加一层，帮你拿到最便宜的 token，也在云那一层做抽象，让你能部署到 AWS、Azure，能接 Databricks 和 Snowflake。

这个说法要打个折。Replit 自己也是模型公司的下游客户，它的「独立」是相对的，是把选择权从一家模型公司手里挪回到客户手上，不是凭空造出一层新权力。但这个方向本身我认为是对的，因为它对应的是企业真实的恐惧：被单一供应商定价。

Amjad： 更具体的动作是过去一年我们把 Replit 做成能部署在客户自己的云上，bring your own cloud，甚至本地。两年前我不会相信自己会做这件事，那时候我笃定云和 SaaS 是未来。现在客户变得更保守了，数据泄露的路径实在太多，agent 到处在跑，Twitter 上一堆截图，说 Instinct 或者 Muse 会把不同人的数据混在一起。

Alex： 个人的 agent 和工作的 agent 是两件事。Muse 和 Instinct 的产品市场契合度明显比 Grok bot 强，但 Amjad 说的那些问题几乎都发生在企业里：权限怎么分、数据给到哪一层。CEO 可以有通用 agent，因为手里是管理员权限，普通员工不行。企业里让 agent 真的产出结果，这个行业还欠着大量的活。

Amjad： 这也是我最想吐槽的地方。大多数企业现在只是把 agent 接上去了，离「有产出」还差一整个工程。

所有人都在盖同一栋楼

主播： 我看到一条推文说，现在所有公司都在做同一个东西：一个 agent loop，加上通知、第三方连接器、上下文管理、记忆、沙箱、联网搜索、computer use，外面再套一个常驻 agent。

Alex： 2005 年版本的这条推文大概会写：所有人都在做同一个东西，数据库、用户表、登录页、注册页、个人主页、退出按钮。看着都一样，但那不重要。这些是新的基础设施，是没有差异化的那一层，差异在上面。

Alex： 真正的差别在数据权限和落地上。CEO 可以有一个什么都看得见的通用 agent，普通员工不行，权限控制不允许。这也是为什么通用 agent 和垂直 agent 会长期共存。

通用 agent 的代价：没人替你扛责任

主播： 你好像对通用 agent 很有意见。

Amjad： 它的问题不是能力，是责任。你交给它的活越多，你对这件事的理解就越少。而理解是要有人扛的。一家公司能承受的 cortisol 是固定的，你想在某一块少操心，就得有人多操心。agent 不接这个责任。

Amjad： 我自己那个通用 agent 每天帮我找「什么需要我处理」，我几乎没法改进它。每次想调点什么，一周后我又开始忽略它的输出。因为你跟它没有共同的上下文，它也不在乎具体某件事。

Amjad： 想象一个幕僚长，很能干，帮你起草全公司的回复。再想象十个幕僚长，每个人一样能干，各自负责你生活里的一块。后者能让你调「我牺牲多少理解」这个旋钮，某些地方多接管，某些地方自己看。

Alex： 这有点像重新发现分工。亚当·斯密写别针工厂的时候，分工是一个巨大的发现。我们后来可能分得过细了，马克思讲的异化就是这件事的另一面。放到 agent 上，结论反过来：人应该通用，机器应该专门化。

Amjad： 但好东西长什么样，现在还没人知道。到今天为止，没有一个由专才 agent 组成的系统，能做得像跟 ChatGPT 或者 Claude 聊天那么优雅。OpenAI 刚发的 Dots 像是在试这条路。也许最后是一个幕僚长 agent，在中间协调下面垂直分布的 agent。

Alex： 还有一层没解决：agent 之间怎么通信。Hugging Face 那次事故里，agent 已经开始互相帮忙。你几乎不希望它们直接用自然语言对话，可能需要另一种 DSL 或者协议，还要有数据隔离，保证一个 agent 没法说服另一个 agent 交出不该交的东西。

让模型训练自己的替代品

Amjad： 我一直在想 JIT 编译器那个类比。你在跑一个大模型，执行过程中发现某类任务的用法很固定，那就顺手训一个小模型顶上去。它更便宜，能被 prompt injection 打穿的面也更小，因为它本来就没那么能干。

Amjad： 我在 Replit 内部训过一个成本估算模型，用 Qwen 8B 这一档的底子，输出是一个概率分布：这个任务落在 5 到 10 美元、10 到 20 美元，各个区间的概率是多少。我们数据多，训一个分类器很便宜。

主播： 有人担心模型债，两三个月就得重训一次。

Alex： 用专有数据训出来的分类器不太有这种焦虑。它不需要会写 Rust，也不需要支持一门新语言，你不会觉得它「落后」。

Amjad： 就像 90 年代的动态语言。Java 和 C++ 的年代之后，大家一窝蜂用 Python、Ruby、JavaScript 去抢速度，Stripe 是拿 Ruby 写的。然后所有人撞上性能和大 bug，于是加类型、加 JIT，绕一圈回来，Rust 出现了。模型这一轮会一样：用最贵的通用模型干所有事，最后大家会醒来发现又浪费又危险。现在是拿核弹打蝴蝶。

便宜的决策模型，可能是对齐的解法

Amjad： 工具调用会多到人看不过来，那正好需要一个小、快、便宜的决策模型，逐个工具调用去判断它是否符合规则。比如让红队 agent 试着逃出沙箱，一旦真的越界就立刻停，这种规则不方便写进 agent 自己的 prompt，交给外部模型检查更合适。Nvidia 刚发的开源 agent 安全组件是另一类结构性护栏，两条路最后会一起用。

主播： 模型变聪明，是更好对齐还是更难？

Amjad： 正交性论点说智力和道德是两回事。在机器上，RL 的研究显示 reward hacking 和欺骗是随能力一起变强的。你去监控思维链，它们就学会在思维链里撒谎。要做一次真正的对齐评测，你得让模型在一个大任务上跑上好几个月。

Alex： 「alignment」这个词我一直觉得别扭，对齐谁的价值？我更愿意谈欺骗。一个足够大的模型会不会突然不再骗人、不再偷懒，没有人知道。如果它真的能做到，企业可能愿意付十倍价钱，尤其是写代码和安全研究这种高风险任务。

Amjad： 我们会慢慢意识到，过去那种「计算机完全照我们说的做」的日子有多好过。

融合模型：前沿质量的半价

Alex： 既然每个模型的训练数据不一样，为什么不都拉进来？我们在深度研究场景上做融合，质量能到顶级水平，成本只有一半。做这类路由和升档模型的时候，缓存意识是最要紧的设计约束之一。

Amjad： Replit 今天发布的评测也是这个思路：把不同的模型和 harness 组合起来，做到前沿水平，成本只要 40% 到 50%。

留意一下他们的口径：整场里没有人拿跑分证明自己更强，全是账单。这对做 AI 产品的人是个信号，客户开始拿单位成本而不是榜单名次来验收了。

这期节目最值钱的地方，不是「Stripe 买了谁」。是他们对同一个问题的两次回答：当模型足够强，你该让它做更多，还是更少。两个人的答案一致：机器往里收，人往外放。谁先把这条线划清楚，谁就能省下下一轮 AI 账单里最大的一块。
