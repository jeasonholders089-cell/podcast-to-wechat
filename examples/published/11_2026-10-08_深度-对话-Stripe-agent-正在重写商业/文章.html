Stripe 2025 年处理了 1.9 万亿美元支付流水，同比涨 34%。这是 John Collison 做 Stripe 的第 17 年。

10 月 5 日，播客 Sourcery 的主持人 Molly O'Shea 在 Browserbase Navigate 大会的台上把 John Collison 请了上来。两个人聊了 28 分钟，题目是支付、agentic commerce，还有 computer use。

这期里最值得记的是两个判断。一个是他把 2026 年 1 月 1 日叫成 singularity epoch 第一天，理由是写代码的模型在去年年底突然好到让人「坏了」一下。另一个更具体：现在没有人手动集成 Stripe 的 API 了，他们派自己的 coding agent 过来做。开发者的手感和 AI 的手感不是一回事，Stripe 得重新定义自己擅长什么。

  • 嘉宾：John Collison（Stripe 联合创始人兼总裁）
  • 发布：2026 年 10 月 5 日，28 分钟

01 填表这件事，本来不该由人来做

Molly： Stripe 2025 年处理了 1.9 万亿美元流水，涨了 34%。你打算怎么为 AI 重建这套东西？

John： 我们做 Stripe 到今年是第 17 年。支付行业很多年没怎么变过，最近开始有一些小的变化。稳定币那块先放着不说，其他还是老样子。

John： Instinct 是真的，Muse 是真的，这些工具都是真的。你看今天在座的人，相当一部分已经在用了。这里面有一个基本判断：填网页表单对任何人都不算一件有产出的事，没人会在业余时间选择去填表单。

John： 所以这些个人 agent 能成立，前提是两条。一条是给它足够的算力，让它真的能出去办事；另一条是 computer use 成熟到能用的程度。有了状态化的上下文，agent 知道你的收货地址、支付信息，还能操作一台电脑去现实世界里做事，你说一句「帮我把驾照续了」，体验就完全是两回事。

John： computer use 是现实世界的终极向后兼容层。你不可能等车管所加一个 MCP server，那得起码再等几年。等不了也没关系，直接用 computer use 绕过去。

02 代理式商务：先改买卖，再换一批赢家

Molly： 你说 agentic commerce 是一次彻底的重排。重排在哪里？

John： 分两层。第一层在表面，商家卖东西的方式会变。第二层在结构，商业格局本身会动。

John： 我的预期是，人的 agent 会承担很大一部分购买行为。我自己的体验是，用 AI 做产品调研，经常搜出来一些你没听过的小众品牌。这对长尾商家是好故事：只要产品评价是真的好，网上有人喜欢，AI 反而会让它更容易被找到。

John： 现有的聚合平台要回答一个问题，因为 AI 发现正在变成商业新的聚合点。排名靠前的商家会换一批。产品好、能被发现，你就能往上冲。

John： 这件事有个类比。Facebook 和 Instagram 的广告定向好到一定程度之后，长出了一代原生公司。Wish、Teespring，Temu 和 Shein 也在相当程度上是靠这些平台的投放长大的。它们比上一代大卖场更原生，抢客户的能力更强，这种优势最后会一路传导到产品设计本身。AI 电商会有点像：一开始只是买东西更方便，后面会重新排一遍商家和产品的座次，赢的是最能把新能力用起来的人。

03 网络安全：未来五年会看到更多泄露

Molly： 规模上来之后，你怎么看网络安全风险？

John： 我们发明了一项新技术，它同时交到了防守方和攻击方手上。有人拿汽车打比方：最早用汽车抢银行的是劫匪，很快警察才反应过来，自己也需要车。攻防一直是猫鼠游戏。

John： 新模型把攻击能力推上去了，说实话有点吓人。好消息是 Stripe 在安全上本来就很偏执，做了很多年。但对手变强的速度确实快，我们从「已经很重视」变成「投入更多」。

John： 未来五年你看到的泄露事件会比过去五年多。这话没什么可绕的。理论上攻防会走到某种平衡，但这种假设太理想化了。现实里大量组织采纳新能力太慢。

John： 对创业者来说这反而是好消息。初创公司的负担轻：技术栈小、结构统一，换最新模型很快。如果你跑的是五十年前的老系统，还通过收购攒了一堆互相不兼容的东西，甚至在跑已经停止支持的 Windows 版本，那位置就很难看了。

04 2026 年 1 月 1 日，singularity epoch

Molly： 你聊 singularity 的说法比旧金山主流的末日叙事乐观。你怎么看？

John： 我们在 Stripe 有点半开玩笑地把 1 月 1 日说成「奇点第一天」。Unix epoch 定在 1970 年 1 月 1 日，singularity epoch 就定在 2026 年 1 月 1 日。

John： 日期不是随便挑的。去年年底，写代码的模型突然好到一个程度，对很多人来说是「坏了」的一刻。AI 圈子一直在讲递归自我改进，AI 帮 AI 变得更好。把 AI 当成一个整体来讨论，容易糊掉细节，但我们现在确实在一个能力互相加速的世界里。

John： 你看这两周数学界那一串发布。我们进入了 math wars，2026 年会有数学战争，这件事不在我的清单上。模型实验室也一样，在拿 AI 能力让自己跑得更快。

John： Stripe 这边偏乐观，因为我们能看到一些早期的经济信号。智能变便宜之后，新公司注册的数量明显上去了，是我们在平台上近些年见过最高的水平。工具够了，开公司更容易，做成的概率也更高。

John： 我们说 singularity 不是出于悲观。现在就在起飞的过程里，你该享受它，而且很难否认它正在发生。

05 该害怕吗：怕具体的事，别怕气氛

Molly： 那到底该不该怕，还是这只是营销？

John： 该做的是保持警觉。我们跟企业客户聊网络安全，会讲得很直接：这些都是真的。

John： 还有一个例子能说明整个盘子在动。Stripe 前面十几年都在为开发者建东西，把 API 的体验当成卖点，文档的细节、版本迁移顺不顺，内部花了巨大的力气。

John： 现在没有人手动集成 Stripe API 了。他们把自己的 coding agent 派过来做。这是相关但不同的技能，开发者的手感跟 AI 的手感不是一回事。我们花力气做好的那些细节，对 AI 未必重要；对 AI 重要的东西完全是另一套，比如它太容易接错 API 版本。我们得重新定义 Stripe 内部擅长什么。

John： 这件事对在座所有人大概都成立：每个人的棋盘都被晃了一下，有些棋子被碰歪了，局面变了，你得按新的局面下。

John： 该担心的是具体的事，比如你的网络安全到底行不行。不要让一种笼统的压迫感罩住自己。活在一个快速起飞的世界里，应该感到兴奋。

06 买公司：Metronome、Bridge、Privy、OpenRouter

Molly： Stripe 最近收购了 Metronome、Bridge、Privy，还有 OpenRouter。你在拼什么？

John： Stripe 的收购基本跟着一条线走。Bridge 和 Privy 在加密这条线上，加密世界有自己一套工作方式，那种 crypto-native 的手感，靠内部慢慢长出来会很慢，他们把这部分注入了 Stripe 的文化。

John： Metronome 做 usage-based billing（按用量计费），因为 AI 来了。今天每家公司都有推理成本，定价方式必须跟着改。现在很少见到一个产品完全没有按量计费或者超额的部分。你订阅 ChatGPT 或者 Claude，用满额度之后，它会告诉你额度没了，要买 credits。

John： OpenRouter 是另一件事。Stripe 自己也重度用 AI，我们注意到企业支出里流向 AI 和推理的比例在涨，而且涨得很快。你要论证这笔收购，得先相信一件事：一家公司内部会同时用多个模型。

John： 这是 OpenRouter 的判断。同一个业务里，不同任务该走不同的模型；新模型出来要能换过去；一个高价值用户可以送进前沿模型，低价值用户就走便宜模型，取决于这个用户对你的终身价值。你如果相信一家公司需要同时用多个模型，你就需要 OpenRouter 这样的东西。据我们判断，他们把这件事做得最靠前。

07 build 还是 buy：一块新肌肉，买比建快

Molly： 什么时候决定自己建，什么时候决定买？

John： Stripe 早期我会去找体量大得多的公司的负责人问这类问题。我问过 Box 的 Aaron Levie 产品优先级该怎么做，他说你列一个大清单，然后做影响最大的那些。听起来很可执行，实际也就那么回事。

John： build 还是 buy 是一样的道理：买那些你买比自建更划算的公司。差别在手感上。

John： 我们过去买的，基本是 Stripe 核心之外、或者核心边上但属于新肌肉的东西。token routing 这种能力，我相信 Stripe 能学会，但要花很久。接下来要问的是市场变得有多快。OpenRouter 这个市场，今天跟十二个月前完全不是一回事，十二个月后又会是另一个样子。一个新且快速变化的市场，等你把内部团队建起来，做出来的东西可能已经过时了。

08 内部：销售和法务自己搭 AI 应用

Molly： Stripe 内部最大的变化是什么？

John： 大家应该都体验过所谓 jagged frontier，AI 的能力边界是锯齿状的，有些领域很强，有些很弱。网上有大量语料的任务，它做得还行；没有训练数据、必须从第一性原理推的任务，就差很多。

John： 组织层面有对应的版本：你在随便一个消费级 AI 应用里可以玩，但在大多数商业场景里不能这么干。你要问的是带业务上下文的问题。所以我们搭了内部工具，很多公司都有类似的东西。它的价值在于把 AI 应用接到内部数据上。

John： 这件事复杂的地方在权限。有人需要看 HR 数据库，但不是所有人都该看。还有正确性的问题。这些做好之后，你手上就有一个能在内部数据集上工作的 AI 应用，威力很大。

John： 我们的销售团队工作流已经完全变了。他们自己搭应用，去拼一个客户可能关心的数据组合，做个性化提案。这些应用不是我们替他们做的，是他们自己建的。法务也差不多。

John： 举一个例子：全球运营意味着法规永远读不完。印度刚掉下来一份 600 页的新法，你读了吗？不好意思，我还在读芬兰那份 600 页。有人自己搭了一个 agent 来消化新的监管文本。

John： 个性化的软件这件事，行业已经讲了几十年。现在门槛终于低到能看见大量真实产出。computer use 也是同一个逻辑。我们经历过 transformer，然后基于 transformer 有了 LLM，再往上加 RL，中间是几次台阶式的跃迁。我认为好的 computer use 会被看成下一次跃迁，因为它是给现实世界补的那层兼容性。

09 信息摄入：vibe code，和走出 Soma

Molly： 你怎么跟上所有新研究和进展？

John： 跟所有人都一样。我知道有人说自己睡前读十篇 AI 论文，我不做这个。我也不确定他们真的做。

John： 我会 vibe code 自己想用的应用，这件事很好玩，而且真能用上。另一件事是不断跟 Stripe 的客户聊他们在做什么。我们盯着平台上增长最快的公司，Browserbase 这样的早期公司，正在变成 Stripe 上很大的客户。看冰球要去的地方，而不是它现在在哪。跟增长最快的公司待在一起，你自然会被带到 AI 旁边，因为快的地方就在那儿。

Molly： 有没有更「模拟」的东西帮你保持专注，不至于得 AI 精神病？

John： 谁说我沒得？

John： 正常人的那些事就有用。去自然里，偶尔把手机放下。这里是加州，全球最好的地方之一，穿过金门大桥到 Marin 就恢复得很快。来开会的人如果住在联合广场，关键是走出去，别在那个街区的半径里待着，特别是 Dreamforce 期间。我的建议就这一条，顺便也能防 AI 精神病。

Molly： 我常来这儿，但不在这住，看到有人来这儿旅游会觉得奇怪。

John： 当然有人来，这里美。

Molly： 我习惯了把它当成办公园区。别人是冲着文化来的。

John： 那倒未必算文化。

Molly： 历史。

John： 对，自然。

10 没人问的问题：机器人检测之后是什么

Molly： 这个时代有哪个问题没被问出来，但该问？

John： 有一个在问，但会变得越来越尖锐：机器人检测。

John： 很多网站都做 bot detection 和 bot prevention，这么做可以理解。问题是以后访问网站的大部分都是 bot。你需要的是一套新的东西：把好机器人和坏机器人筛开。现在正好卡在中间，新的平衡点长什么样，没人知道。

John： 我建议你去玩一下 Instinct、Grokbot、Meta 的 Muse，或者任何一个这类助手，它们是很强的「接下来会发生什么」的体感。这些产品会带来 AI 产品新的形态。

11 17 年：没有捷径

Molly： 做了 17 年创始人，你最大的教训是什么？

John： 如果要把 Stripe 的故事压缩成一条，就是没有捷径。Stripe 从来没有过 South by Southwest 那种一夜爆发的时刻。有时候我们会去拨一下增长的旋钮，想确认「这东西开着吗」，它就是一直在涨。每一年都比上一年大，就这样连着做很多年，最后到了 1.9 万亿。过程中从没有过「天哪，这事成了」的感觉，反而常常是「增速比去年低了一点，但绝对值更大了」。

John： 我们每开一个产品，一开始都很小、像玩具。很少有产品在当时的观感里像公司的未来，我们只是做一个觉得对客户有用的东西。

John： Stripe 身上有一种「熬」的成分。我们没退出，也没被收购，就是一直在原地磨。这件事在技术故事里被低估了。Nvidia 现在全球最大，他们从九十年代开始做 GPU，然后做更好的 GPU，中间想到了 CUDA 这类改进。也有很长一段时间 Nvidia 没今天这么热。

John： 我们尽量跟人打长局，无限游戏。对合作方做对的事，被当成好打交道的对象。这个名声很重要。

John： 还有一条写在 Stripe 的经营原则里，第一条是 users first。做产品先从用户真正想要什么出发，倒着推。公司很容易飘，开始讨论该进哪个市场、哪里有一块新的收入池，全是内部视角。那种事做做也无妨，但别从那儿开始。

写在最后

John Collison 这期没有任何一句是在讲「AI 有多强」。他讲的都是接口：表单不该由人填，API 不该由人手接，发现商品这件事不该由聚合平台来定，权限和正确性才是内部 AI 真正的工程量。1.9 万亿的盘子他讲了 11 个小节，最锋利的一句反而是「没有人手动集成 API 了」。这句话对 Stripe 是转型压力，对做产品的人是机会清单：你上一次认真看自己的 API 文档是什么时候，看它的人还是不是人。
