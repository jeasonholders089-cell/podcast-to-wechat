粽子AI世界 · 深度

Sources 播客 · Alex Heath 对话 Matan Grinberg（Factory）· 2026-09-29 · 50 分钟

「AGI 已经来了。我们现在就活在一个后 AGI 的世界里。」

说这话的人叫 Matan Grinberg，Factory 的联合创始人兼 CEO。Factory 做的是给企业写代码的智能体（agent），产品叫 Droid。节目简介里给的数字是，这家公司的估值已经到了 50 亿美元。它 2023 年 4 月 17 日成立，今年年初团队 30 人，年底会到 300 人，伦敦、悉尼、东京的办公室一个接一个开出来。

主持人 Alex Heath 在 Sources 里和他聊了 50 分钟。开头是行业里的老问题，一年前大家还在用 IDE 补全，现在企业已经在讨论要不要把整段迁移交给 agent。聊到最后，Matan 给出了一个更大的判断：所有说自己正在迎接 AGI 的人，可能都晚了一步。

他对行业里最流行的一种恐惧也没留面子。在他看来，「AI 会让所有工作消失」这类话，很大一部分来自说这话的人需要它成立。

主要观点

  • 企业认真用 coding agent 是今年的事，转折点和 Karpathy 在 X 上晒自己的用法有关。
  • AGI 不是一个即将到来的时刻。Matan 认为人类已经适应了它，把恐怖的新能力当成了基本盘。
  • Factory 的生意压在一个判断上：没有哪家模型提供商能长期通吃。模型路由（model routing）是产品核心。
  • 企业不缺 token，缺的是能赚钱的结果。Factory 靠卖产品保持正毛利，不靠转卖 token。
  • 工程师这个工种不会消失，人会变多，只是很多人以后不再管自己叫工程师。

「未来是无 IDE 的」

Factory 的第一版官网写过一句 slogan：the future is IDE free。那是 2023 年，GitHub Copilot 刚被一部分人用起来，多数人的体验还停留在补全下一行。

他们当时的做法像个小游戏。一边放 IDE，一边放 ChatGPT，人一行代码都不写，只负责复制粘贴和给方向，看能不能让模型把整个任务做完。答案是能，前提是上下文给得够，问题拆得够细。

Matan 从这个游戏里得出了一个结论：自主 agent 能不能成，取决于上下文给得够不够、问题拆得够不够细。模型每强一点，人需要拆的部分就少一点。IDE 补全只是一个过渡形态。

那句 slogan 让招人变得很难。数不清的候选工程师因为不认同它直接退出流程，公司差点把它从网站上撤掉。它也筛掉了只想加入一家有酷投资人的创业公司的人，留下的是真相信这条路的人。今天已经没人觉得这句话有争议。

AGI 已经来了，只是我们把它当成了基本盘

Matan 的解释很直接。如果把今天 Factory 能做的事情拿给四年前的人看，所有人都会吓到。人的反应是惊讶一个星期，然后把它当成起步价，接着问下一个是什么。

他承认这个判断里有一部分让人松了口气。行业里有人认定所有工作都会消失，也有人翻就业报告说几百万个岗位正在被创造出来，两边都是聪明人，分歧却这么大。他选的是第三条路：我们已经在里面了。到目前为止没有什么失控的事发生，需要解决的问题还很多。

数字上，他看到企业侧的 token 消耗同比涨了十倍以上。更直观的变化发生在工程师这个身份本身。三年前做工程师和十五年前做工程师，几乎没有区别；三年前和今天比，是两个世界。

押注没有一家模型能通吃

模型路由是 Factory 从头就在下的注。同一个任务，有时需要最强模型，有时只需要一个便宜快速的模型；有时只要求这周做完，那就用慢一点、便宜一点的。路由器按性能、延迟和成本动态切换。

Matan 打了个比方：早上你想吃吐司，你不会关心电是从哪来的。

他认为企业迟早都要站到模型无关（model agnostic）这一边，因为没有人能预判下个月前沿会跑到哪家。OpenAI 结束和 Cursor 的长期合约，Cursor 加入了 Elon 的阵营，这件事在他看来是对这套判断最大的验证。客户突然发现自己用不了某个模型，对任何一家公司都是最现实的教训：不能有单点故障。

他也没假装中立。他承认这个判断对模型公司以外的所有人都有利，也承认说这话的人需要它成立。这段判断最值钱的地方，是他把自己的利益位置先亮了出来。他只补了一个理由：整个自由市场都希望它成立，而如果真的出现一家模型强到通吃所有对手，那会变成「终结所有垄断的垄断」，政府不可能站在旁边看。

企业买的不是 token，是能赚钱的结果

「转卖 token 的人，毛利一定是负的。解决别人问题的人，才有机会做出正毛利。」这是 Matan 对当下 AI 商业模式最锋利的一句判断。

他顺手讲了一件不太好听的往事。头两年他们做 code review agent 和代码生成 agent，客户并不满意。团队判断产品需要一次大转向，于是把已经收到的钱退回去。对投资人来说，这等于亲手把增长曲线砍掉一块。Matan 的说法是，他要的是几个月后产品真的能用时，客户还愿意开门。

谈到同行，他把市场分成三类：训练模型并做应用的实验室（OpenAI、Anthropic、Google、SpaceX、Cursor），用工具替客户做项目的服务商（他说这是新一代的埃森哲），以及 Factory 这种只把工具交到开发者手里的公司。他把 Cognition 归到第二类，理由是对方更像 Palantir、埃森哲和德勤，靠大量 FDE 进场交付。他的目标是把工具做得好到一个 FDE 都不需要。

关于 FDE 这个词，他给了一个冷静的注脚：标签几年后可能没人再用，这个技能不会消失。技术问题解决型通才永远有用，只是名字会从解决方案工程师、售前工程师，换到下一个叫法。

工程师会更多，只是名字会变

Matan 不认为工程师的权力正在结束。他的判断是，能动性（agency）最高的人会借这些工具浮上来。

理由是关于「约束」的。代码正在变便宜，真正稀缺的是约束：一个模糊的问题摆在面前，最好的工程师能把它拆成一组必须满足的多维条件，然后找到那个最优解。写代码只是满足约束的过程，过去它贵，现在它越来越便宜。他说这就是工程师薪水高的原因，他们是最擅长系统思考的一群人。

他用摄影做了个类比。一百年前，世界上只有少数人能当摄影师；iPhone 出现之后，每个人的相册里都有上万张照片，只是大部分人不会自称摄影师。同样的变化会发生在工程上：会有更多人做以前被叫做工程的工作，他们未必叫自己工程师。

招人这件事他也改了做法。现在非 AI 的编程面试没信号，用 AI 的编程面试信号也弱，因为大部分人都能靠 AI 解出来。他看两样东西：思考速度，以及愿不愿意把全部精力压在这一个问题上。他发现自己做过物理，说写作是能动性最强的行为之一，愿意把脑子里的想法写下来、发出来，本身就是一种表态。最近他更常直接从外面收购小公司，因为判断一群人比判断一个人更快。

沙盒是你自己挖的坑

Matan 对安全话语的怀疑，落在一件具体的事上。模型从沙盒里跑出来闯了祸，他的态度是责任必须落到把人请进来、又在家门口挖坑的那一方。他讲了个不好听的比喻：我请你来我家，门口的坑是我的，你掉进去，该被追究的是我，不是所有有房子的人。

在他看来，把模型当成有自主意志的东西，是一种隐性的免责。善意不等于正确，历史上很多做错事的人都以为自己是在做对的事。他还提醒了一层：大公司推着监管往前走时，门槛同时也在变高，小公司更容易被挡在外面。

结论

「AGI 已经来了」这句话站不站得住，取决于你坐在哪张桌子上。企业把代码交给 agent 这件事，已经不需要口号来证明，预算和工时都在变。这一段窗口期里，先把约束想清楚的那家公司会先拿到结果。
