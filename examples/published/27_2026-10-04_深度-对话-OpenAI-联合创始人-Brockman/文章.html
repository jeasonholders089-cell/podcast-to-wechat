对话 OpenAI 联合创始人 Greg Brockman｜2026-09-30｜30 分钟｜Silicon Valley Girl

先说结论。OpenAI 联合创始人 Greg Brockman 说，他现在不写代码了。

原话是：「我很擅长写软件。我不再写了，我指挥 AI 去写，我提供反馈和方向。」

一个把「写 C++ 还是写 Swift」当门槛的时代，被这句话划掉了。那剩下的门槛是什么，他在这期访谈里给了几个很具体的答案。

主要观点

  • ChatGPT 每周有 12 亿活跃用户，但一个人要找到三种真实用途，才会留下来
  • Coding agent 的转折点在 2025 年底，AI 从写你 20% 的代码变成写 80%
  • 小公司最先卡住的不是工具，是野心的天花板
  • Agent 的下一站是主动干活，把事办完再来找你批
  • 与其纠结用哪个工具，不如手动做五遍，再谈自动化

12 亿周活，卡住大家的是第三个用例

OpenAI 每周有 12 亿活跃用户，其中 3 亿人每周拿它问健康相关的问题。两个数字摆在一起，AI 看起来早就普及透了。

Brockman 的解读是反的。他说，一个人只有把 ChatGPT 用出三种不同的用途，才会变成重度用户，留下来，用得更多。

凑到三种用途，这件事非常难。

他的形容很形象。摆在你面前的 AI 什么都能做，那你先让它做哪一件？用户要的也不是按钮、滑块、模型选择器，是一个能直接对话、能解决问题、还会主动提建议的东西。他提到自己录制播客前的一个场景：Agent 发现他有封拖了两天的邮件，替他查完背景，起草了回复，然后问他一句，你批准吗。

主动，是这场对话里出现最多的产品方向。

不写软件之后，角色变成了「指挥」

主持人问他，怎么判断自己正在做的东西不会被下一代模型抹掉。

Brockman 给了一套很实用的分类法。有些活会随着模型变强而变大，有些活只是在绕开模型的限制。后者不好持续，历史上做提示词包装、做手工拼接的团队，活得都不长。

他还给了一个具体时间点。2025 年底，coding agent 时代真正开始，AI 在你代码产出里的占比从 20% 跳到 80%。产品的形态必须跟着换，因为模型每上一个台阶，就会冒出一个新的界面形态。2022 年是聊天框，GPT-4 之后是另一套东西，现在是「个性化 agent」的起点。OpenAI 刚发布的 Dots 就在这个位置上。

Dots 的形态值得看一眼：它有自己的一台云电脑，也可以选择接上你的本地电脑。Brockman 特意拿它和以前的 coding agent 做对比，那些 agent 是任务式的，住在你的笔记本上，你合上盖子它就停工。他说，那从来不是我们五年前想象的 AI。现在这一版才像。

小老板卡住的不是工具，是野心

访谈里最有画面感的一段，来自一位普通用户。

OpenAI 的一名员工去逛古董表店，和店主聊起 AI。店主的第一反应是，我一个卖表的，用不上。员工让他先把问题说出来：店里没有网站。于是他对着语音说了一句，帮我建个网站，做得漂亮点。店主又补了一句，每块表都有自己的故事。这些故事被填进去，变成了一个像样的页面。

Brockman 还提到一对失明的兄弟，他们用 ChatGPT 处理日常和工作里的事，包括把线插到电脑正确的接口上。放在几年前，这种事只能开口求人。

他把结论落在野心上。每个人的口袋里现在都装着一个博士级智力、一个世界级商业顾问，小生意的启动成本被压到很低。企业主要重想的问题变了一个：如果你真雇得起全世界最好的程序员，你会让他去做什么？

然后是他那句原话：「我们都可以把野心的天花板抬一抬。」

企业软件和消费软件的界线会糊掉

主持人提到一个数据，YC 最近几批项目里 60% 是 B2B，然后问，消费端的创业会不会回来。

Brockman 的答案是界线会模糊。推理落在一个老概念上：企业销售的本质是关系。它之所以成不了消费业务，是因为消费者太多，一个个维护关系的成本太高。如果 AI 能把你的关系能力放大到同时照顾很多人，这套对企业销售的打法就有可能搬到消费业务上。

他接着往更大的方向推。公司会变得不那么「公司」，不再是几万人按固定方式组织起来的集合。未来一到两年，他认为会看到创业的大规模复苏。

这里我插一句自己的判断：他的乐观有前提，前提是模型能力继续按现在的斜率变强。如果进步变慢，先被挤掉的恰恰是那些把宝全压在下一次模型升级上的产品。

Agent 现在能干到哪一步

主持人提了个很锋利的要求：别讲早安简报，讲一个能真帮你管公司的配置。

Brockman 没回避，反而把早安简报拆成了三层。

最浅的一层是把信息推给你，那些东西你自己刷通知也能看到。往上一层，是把待办按优先级排好，告诉你哪些人你还没回。再往上一层，是他所说的「我们现在的位置」：跨一堆资料做深度研究，把决策需要的要点压成很短的一段。

他更期待的是再下一层。Agent 直接替他打电话，找同事，找外部合作方，把事情全部对齐，最后只需要他点一次批准。

背后的基础设施已经在了。Brockman 会把关于 OpenAI 的问题直接丢给 agent，让它去查数据仓库，算留存曲线，看某个市场的增长。他说在 Stripe 的时候，这类问题要发邮件给数据团队，一周之后才有答案。

他还给了一个很好的验证方法。想知道一家公司有没有被 AI 改变，就去看模型挂掉两个小时时大家的反应。所有人都说，我没法工作了。他的吐槽是，六个月前你还没有这个东西。

别问用哪个工具，先手动做五遍

很多人卡在第一步，不知道从哪开始。

Brockman 的回答是从小事开始。找一个生活里的小痛点，可能是一封你一直拖着没回的邮件。先想清楚怎么把邮件喂给 AI，可以复制粘贴，也可以把 Gmail 的连接器接上。手动做三次、五次之后，你就能看懂整个过程，再谈自动化。

他说这是软件工程的老规矩，同一件事手动做五遍，就该考虑自动化了。

他还顺手布置了周末作业：注册 Dots，把上下文接上，给它派一个具体任务，让它去买个东西，或者设一个周期性任务，或者做一次研究。

什么不该交给 AI

这点上 Brockman 很克制。他说人必须保持控制和决策权，目标得来自人，技术的作用是帮人做到更多。所以谈到该建什么，他讲的是护栏、信任、可监督性。

往前看，他把科学发现列为最容易被忽视的一块。为了攻 Navier-Stokes 方程，OpenAI 投入过一万个 agent 连续跑了好几天。他不觉得这种规模只是大公司的特权：只要你把算力指向重要的问题，并愿意把 token 预算拉高，回报会大得不成比例。

他最后描述的画面是，能解开未解数学题的 AI 会进到每个人手里。药物发现、材料科学都会跟着变。以前必须动员一小撮专家才能解决的问题，以后人人都能上手。

工具的门槛已经降到接近零。接下来拉开差距的，是你敢把目标定得多大。
