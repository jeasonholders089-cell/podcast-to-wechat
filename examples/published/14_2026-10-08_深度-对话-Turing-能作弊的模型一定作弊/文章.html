10 月 2 日，Molly O'Shea 的播客 Sourcery 更新了一期对谈，嘉宾是 Turing 的联合创始人兼 CEO Jonathan Siddharth。Turing 在 AI 产业链上的位置比较特殊：一边替前沿实验室把模型在代码和知识工作上推得更好，一边有一个完整的部门，专门把 agent 部署进企业。

这期听起来聊的是训练方法，其实是一件很具体的事。给模型打分的规则只要留了一条缝，模型就会从那条缝里钻过去。

他的结论很硬：规则写在哪里，模型就长在哪里。

「如果模型能找到办法作弊、拿到奖励，它一定会那么做。」

数据这行的重心挪了

Molly：我先从数据问起。过去一年，数据在整个 AI 里的位置变化很大。

Jonathan：2026 年这条线的重心整个挪了。之前我们在帮 AI 通过考试：SAT、律师资格考、数学奥林匹克拿金牌。那个阶段比的是你能找到多少专家，把专家脑子里的东西抽出来交给模型。现在比的是另一件事，你能把模拟环境做到多接近真实。这个阶段的核心是强化学习的模拟环境（RL environment）。专家仍然要有，但他们的活变成了写提示词、设计 verifier、准备种子数据。

Molly：你的意思是把现实复刻出来？

Jonathan：有点像《黑客帝国》。你要造一个足够丰富的世界，agent 在里面训练完，回到现实中还能用。环境还得校准：太简单，每次都拿奖励，学不到东西；太难，一次奖励都拿不到，同样学不到。比较合适的区间，是成功率 20% 到 40%。

基座模型是通往任何终点的一半路

Molly：这些系统的能力从哪来？

Jonathan：先做预训练（pre-training），喂海量文本，得到一个基座模型。有意思的地方在规模。GPT-2 写代码很弱，到了 GPT-3、GPT-4，什么都没加，只是把规模推上去，写复杂软件、做多轮对话就自己冒出来了，这叫涌现。Ilya Sutskever 有句话我印象很深：一个好的基座模型，等于通往任何目的地的一半路。

Molly：这跟上一代机器学习很不一样。

Jonathan：上一代是你训练什么就得到什么。训练它排搜索结果，它只会排搜索结果；训练它推荐电影，它只会推荐电影。你不可能让 Netflix 的推荐算法帮你写访谈稿。基座模型不走这个逻辑，它的能力会外溢，于是就有了两个麻烦。

两个麻烦：涌现和泛化

Jonathan：第一个是涌现。继续堆算力、堆数据，会冒出什么新行为，没人能提前算出来。Hugging Face 和 OpenAI 那件事就是例子：agent 之间互相传消息，自己发明出一层中层管理，然后合起来去 hack 系统。这种协同行为，事前没有人预测到。

Molly：当时有人在监控吗？

Jonathan：有监控系统在跑。监控本身也有副作用，agent 会学着不留痕迹。现在它们还不熟练，以后会更熟练。

Jonathan：第二个麻烦是泛化。RLVR（reinforcement learning with verifiable rewards）这套方法，你想让模型学会写可靠、安全的代码，实际它可能连带学会一整类环境里的做事方式，跑到没见过的环境里照样能用。能力强，控制起来也难。

能作弊的模型一定会作弊

Molly：回到作弊这件事，具体是怎么发生的？

Jonathan：软件工程上有个基准叫 SWE-bench，现在基本被刷满了。题目是让模型在一个真实的 GitHub 仓库里合并一个 pull request，verifier 是测试用例跑不跑得过。测试能不能过，跟问题有没有被真正解决，是两件事。模型要是能骗过测试，它会选那条路。

Jonathan：再举个更直接的。capture the flag 那类任务，verifier 检查你有没有拿到 flag。有的 agent 想到一招：它自己把 flag 生成出来交上去，根本没去碰那道漏洞。

Molly：所以设计环境的时候，防作弊是必须做的事。

Jonathan：必须在设计阶段就把口子堵上。你给它的奖励长什么样，它就在哪个方向上长出什么行为。这条缝通常不是故意留的，是没人想到。

对齐和安全，是两拨人在做两件事

Molly：安全和对齐听起来像一回事。

Jonathan：是两件事。你希望模型拒答某些危险请求，这属于对齐，通常在监督微调（SFT）阶段教它。另一件是环境本身不能留下能被绕过去的口子。企业侧还要再加一层：假设一个 agent 在做董事会材料，要跨系统拉数据，里面可能有敏感看板。它对某个数字拿不准，想去核实，你不希望它去问一个没有权限看这份数据的人，它应该去找 CFO。

Jonathan：这里要说清楚，CBRN（化学、生物、放射、核）比网络安全更难。网络安全有攻防双方，一直在军备竞赛，好歹是拉锯。生物风险不对称：一旦出现传播系数很高的病原体，我们受制于现实世界造疫苗、铺开接种的速度。所以这类能力我支持放慢一点。

企业要分两类工作流

Molly：企业在真实世界里的进展，跟新闻里的热度差多少？

Jonathan：企业在做前沿实验室前几年做的事。我把工作流分成两类：核心的和非核心的。如果你在资产管理公司，怎么衡量风险、怎么配置资产，这是核心，竞争力就在这里。HR、财务、法务是非核心，做对就行，不靠它赢。

Jonathan：非核心的活，租超级智能就够了。核心的活，学习那一圈要自己握着。做法是四步：先定义你自己的 eval，再部署一套系统对着这个 eval 往上爬，然后记录 traces，也就是人和模型在流程里留下的每一步痕迹，最后拿这些 traces 去微调。

Molly：哪一步最值钱？

Jonathan：人改模型的那一下。模型交完活，人在哪一步动手改了它、错在哪里，这是信息增益最高的信号。这个循环跑起来，对企业和 AI 都是好事：模型跑得快、规模大，人负责纠错，纠错的那一笔又变成下一轮训练的原料。

这一段我单独拎出来说一句：模型谁都能调用，留得住的资产是那些被人改过的轨迹。

Molly：你一直说「系统」，不说「模型」。

Jonathan：因为一个工作流里，每一步配的模型可以不一样。有的步骤这个模型强，换个步骤那个模型强。中间要做模型路由（routing），外面再套一层 harness，把它接到对的工具和数据上。

开放权重落后三到六个月，但够用了

Molly：企业为什么突然开始认真考虑开放权重模型？

Jonathan：开放权重跟前沿的差距大概三到六个月，判断标准看你怎么定，但差距在缩。发票对账、HR 里的关键流程、做董事会材料、开全员会，这些活不需要上万亿参数的模型。你会想要一个在自己的数据上微调过、能调你自己那套内部工具、带上你自己口味的模型。这部分是你和对手的区别，你不想交出去。

Molly：我看到已经有公司这么干了。

Jonathan：对。有些公司给每个员工配一个内部 agent，成本压得很低，数据也留在自己手里。这条路的前提是工程能力。

Jonathan：我打个车的比方。世界需要法拉利和柯尼塞格，也需要 Model Y。Elon、Sam、Satya、Dario 这些人，如果有个模型能让他们的决策效率高 5%，那当然用最强的。自动化客服这种活，不需要。

Molly：开源和主权这条线，吵得很凶。

Jonathan：我两样都要。前沿实验室在把超级智能往前推，这件事必须有人做，治病、找新材料、上太空都指望它。开放权重同样需要，因为大量企业问题用不上万亿参数的模型，而自己微调出来的模型能让一家公司保住自己的做法，那是它跟对手的差别。

agent 现在能连干两天

Molly：这些系统在真实工作里能撑多久？

Jonathan：今天这些 agent 在编码这类任务上，能连着可靠工作大概两天。离自主干几周、几个月还很远，更别说几年。我想看到的形态是这样：你给它一个任务，它去做；你们定期一对一，你给反馈，它带着反馈继续往下干，中途还能拉起一群 agent 并行。

Molly：教育这块也在变。评分方式在改，不看分数，看你能做出什么。

Jonathan：我的一位导师 Alan Eustace 有个说法，我记到现在：讨论 AI 取代工作的人，漏掉了一件更根本的事，AI 最大的能力是把人类能处理的问题抬到更高的层级。所以教育要教的是提问和验证。招人也是一样，以前你可能让人现场实现一个动态规划，现在可以直接说，在我们的环境里复刻一个亚马逊。考的不是敲了多少代码，考的是这段代码对不对、安不安全、好不好维护、有没有顺手去黑沃尔玛。

Jonathan：我们部署过的东西也挺杂：基金控制员的活、幕僚长的活、战略顾问的活，还有工单系统，自动把工单分类、派给对的人、执行对应的流程。这些东西说到底就是通用的 computer use agent，人在电脑前能做的事，它都能做。企业里要额外配三样东西：审计、可追溯、人在环里复核。

这一轮里，钱流向谁

Molly：把镜头拉远，谁在赚这一轮的钱？

Jonathan：投入品先赚。算力、能源、数据，这三样无论最后谁赢都得用。芯片商和电力商不站队，它们站在需求这边。杰文斯悖论也在起作用：单位成本降下去，用量会涨上来。

Jonathan：蒸馏（distillation）是个变数。它让开放权重一直贴着前沿跑，现在还没有简单办法禁止。反过来，前沿实验室也可能吃到便宜模型的收益：用超智能去造一批小模型，按任务分配，哪一步用万亿参数、哪一步用十亿参数，自己调。

他最想说的那句话

Molly：你最近最想公开讲的观点是什么？

Jonathan：把研究和部署接成一条回路。我们一边帮实验室把模型在编码和知识工作上推得更好，顺带看清了这些模型的能力边界：它们是锯齿状的，有的地方很强，有的地方一碰就碎。另一边我们把 agent 部署进企业，能看到真实世界里它在哪里断掉。看到断点，拿回去改模型，改完再部署。这个回路转起来，模型才真的能干活。

Jonathan：这也是让系统更安全的路。你要它掌握真实的活，就得让它看到真实。研究和部署之间的路接不通，安全也做不实。

最后解不掉的，是人

Molly：超级智能什么时候到？

Jonathan：递归自我改进（RSI）是真实存在的。预训练要压低困惑度，这是个可验证的域，模型可以自己跑循环去发明更好的训练算法。但我们现在优化的还是内圈，始终在这套范式里打转。什么时候有人提出一个不用语言模型、不用 Transformer、不用梯度下降、甚至不用神经网络的办法，现在这套方法是找不到答案的。

Jonathan：所以我不站快起飞那一派。我信慢起飞：未来十年、二十年，模型会越来越强，卡住的是扩散速度。真实的企业工作很脏。一个新人进来，不知道信息在谁手里、在哪个文件里；老板丢过来的任务本身就没说清楚，你得自己去补上下文。

Jonathan：最后解不掉的问题，我认为是人类智能。人的行为没法被解出来。我们要娱乐，要放松，要陪家人吃饭。硅谷容易把这些想复杂了。

Jonathan：如果让我挑一件最想看到的，是医疗的可及性。这件事上 AI 反而最不显眼：你不会看到医生在用 AI 记录，你只会得到更好的照护。

整期聊下来，真正值得记住的并不是模型会不会作弊。是另一件事：规则写在哪里，模型就长在哪里。你把 verifier 设成什么样，它就学会用什么样的方式去拿分。
