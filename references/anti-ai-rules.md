# anti-ai-rules.md · 反 AI 腔规则

机检脚本会按这份规则判定，改稿时逐条对着改。

## FAIL 级（必须改）

| 规则 | 判据 | 说明 |
| --- | --- | --- |
| 破折号 | `——` 出现次数必须为 0 | 中文长破折号是最明显的模型痕迹 |
| 对谈碎片回合 | 单轮发言正文 < 15 字 | 「不。」「说吧。」「好。」必须并进前后论述 |
| 正文配图 | md 里 `![]()` 数必须为 0 | 正文禁图，封面后台单独设 |
| 编译说明 | 文末必须有 `> ` 引用块 | 说明本文是编译稿、观点归嘉宾；正文之前不要出现 |
| 来源四项 | `## 来源` 下必须有 节目/嘉宾/发布/原视频 | 缺项即 FAIL |
| 全文实录 | 正文字数 ≮ 逐字稿承载量 1/3 | 低于就是写成摘要了 |

## WARN 级（建议改）

### 总结套话

综上所述、总而言之、不难看出、由此可见、值得注意的是、众所周知、在当今、随着…的发展

### 互联网黑话

赋能、抓手、闭环、颗粒度、底层逻辑、生态位、打法

### 假升华

不仅是…更是…、值得我们深思、引人深思

### 空转副词

某种程度上、一定程度上、极大地、深刻地、非常、极其、相当

## 改写手法

1. **具体化**：「很多公司」→「他提到的那 200 家公司」
2. **去铺垫**：删掉「在开始之前我们先要理解」这类引子，直接进事
3. **换人称**：把「我们可以看到」换成「我看到的」
4. **拆长句**：一句话只推进一步
5. **保语气**：嘉宾说「这事儿没法算」，不要顺成「这件事无法估算」

## 段落级自检

- 连续三段句式雷同 → 改一段的起手
- 每段都在总结 → 至少两段要落到具体的人、数、事
- 结尾在升华 → 换成一句判断或一个悬念
