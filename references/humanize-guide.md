# 人味化指南

目标：读起来像一个懂行的人在讲事，而不是模型在写说明。

## 可以做的

- 把长句拆成短句；一句话只推进一步
- 用具体数字、具体时间、具体人称替换「很多」「近年来」「业内人士」
- 保留口语里自然的转折词（「但」「所以」「问题是」）
- 引用嘉宾原话时保留他的语气，不要统一成书面语

## 必须避免的

| 类型 | 例子 |
| --- | --- |
| 总结套话 | 「综上所述」「总而言之」「不难看出」 |
| 空转副词 | 「非常」「极其」「相当」「一定程度」 |
| 假并列 | 「不仅…而且…」「既…又…」堆叠 |
| 升华句 | 「这不仅是…更是…」「值得我们深思」 |
| 破折号 | `——`（硬规则：0 处） |
| 段落对仗 | 连续三段同样句式的排比 |

## 对谈体专项

- 主持人短追问必须扩成完整提问，不能出现只有两三个字的提问
- 嘉宾短答并进前后论述，同话题连续短问答可以合并成一次完整问答
- 允许补主语和连接词、顺成书面语、删语气词；不允许新增嘉宾没说过的观点和数据
- 单轮发言正文少于 15 字，机检直接判 FAIL

## 三段式自检

1. 读一遍：哪句像是给领导写的汇报？改掉
2. 删一遍：删掉形容词和铺垫，意思还在吗？还在就继续删
3. 念一遍：念出来别扭的地方就是书面语没顺干净
